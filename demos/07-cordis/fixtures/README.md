# 7.1 的标本

这两个文件是 **7.3 重构之前**的 `src/index.ts` 和 `src/headless.ts`，冻结在这里。

`src/` 里的代码是原地演进的——7.3 把装配拆成插件之后，那两个文件里的重复就没了。
但 7.1 那一课要讲的正是**当时的重复有多少**，所以它需要一份不会变的标本。

`demos/07-cordis/02-duplicated-assembly.mjs` 读的是这里，`05-assembled.mjs` 读的是 `src/`。
两个数字一起看，就是这个阶段的全部价值。

它们是 `.ts` 但**不参与编译**（`tsconfig.json` 只收 `src/`）——它们是数据，不是代码。
